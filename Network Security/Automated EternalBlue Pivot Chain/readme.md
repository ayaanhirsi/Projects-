This report presents the design, implementation, and analysis of an automated penetration testing project focused on exploiting the MS17-010 (EternalBlue) vulnerability within a segmented enterprise lab environment. Using Python automation, Metasploit, and network pivoting techniques, the project demonstrates how a rogue internal attacker can compromise multiple isolated network segments through lateral movement without credentials or manual intervention. The report documents the complete attack lifecycle, including reconnaissance, vulnerability validation, exploitation, pivot-chain development, MITRE ATT&CK and Kill Chain mapping, session management, and remediation strategies. The findings highlight the risks posed by unpatched systems, weak internal segmentation, and inadequate security controls in enterprise networks.
