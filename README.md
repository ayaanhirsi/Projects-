Hi! Welcome to my GitHub repository. This repository showcases a collection of projects I have completed throughout my academic journey, personal learning, and hands on cybersecurity practice.

In addition to cybersecurity focused work, this repository highlights my experience with scripting, automation, and infrastructure management using Python, Bash, and configuration management tools. Several projects demonstrate the implementation of security controls, centralized logging, automated response workflows, and secure network architectures.

The goal of this repository is to document my growth as a cybersecurity professional while sharing the technical projects, labs, and research I have worked on throughout my studies. Each project represents practical learning experiences that strengthened my understanding of both offensive and defensive security concepts.
