This project focused on designing and implementing a secure segmented enterprise network using automation and centralized security management techniques. The environment was built using Ansible to automate the deployment of nftables firewall configurations across multiple systems, including administrative hosts, user machines, an Active Directory/DNS server, routers, and container-based services. A split-DNS architecture was also implemented to provide separate internal and external name resolution using a single DNS server. The project enforced network segmentation through stateful firewall policies, routing controls, and NAT configurations to regulate communication between internal and external zones. Security validation included functionality testing, firewall verification, DNS resolution testing, and simulated attack scenarios such as SYN flood mitigation. The project demonstrates how automation, centralized management, and layered security controls can improve scalability, consistency, and security in enterprise network environments
